# Project guidelines

- Build a simple, single-page website for exploring Google Fonts.
- Keep all content on one page, without navigation or routing.
- Use HTML, Tailwind CSS, TypeScript, and Google Fonts only.
- Keep the file structure flat and easy to understand. Add folders only when needed.
- Prefer straightforward code. Avoid unnecessary frameworks, dependencies, abstractions, and tooling.
- Follow current web standards: semantic HTML, accessible controls, keyboard support, and responsive layouts.

## Communication

- The user has ADHD. Keep responses concise, clear, and easy to scan.
- Use plain technical English, short sentences, and precise terminology.
- Lead with the result or next action. Use short bullets when helpful.
- Explain only what is needed. Avoid repetition and unnecessary background.
